# Some Nights — Nostalgia Music Site

A single-page Next.js App Router nostalgia music player with a cinematic glassmorphism UI.

## Run

```bash
npm install
npm run dev
```

## Assets

- `public/bg/scene-wide.jpg` is a web-optimized version of the supplied landscape scene.
- Add the separately composed portrait asset as `public/bg/scene-tall.png`.
- Add licensed/local audio files to `public/audio/` using filenames such as `channa-mereya.mp3`.

The player is wired to local audio files rather than third-party music hosts.
